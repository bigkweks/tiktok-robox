Privacy Policy

Last updated: June 2025 — RobloxGems / RoboxPipeline

1. What this app is

RobloxGems is a personal content automation tool. It discovers Roblox games, generates photo carousel posts using AI, and publishes them to TikTok on behalf of its single operator. It is not a public service and has no end-users other than its owner.

2. Data we collect
  • Roblox game data — publicly available information from the Roblox public API (game names, descriptions, player counts, thumbnails). No personal data.
  • TikTok OAuth credentials — your Access Token and Open ID are stored locally in a .env file on the operator's own machine. They are never transmitted to any third party other than TikTok's own API endpoints.
  • Content metadata — generated captions, ratings, and post history are stored in a local SQLite database on the operator's machine.
  • No user data — this app has no sign-up, no accounts, and collects no personal information from any person other than the operator.
3. How we use data
  • Roblox game data is used solely to generate TikTok content.
  • TikTok credentials are used solely to call the TikTok Content Posting API on the operator's behalf.
  • Anthropic's API is called to generate game ratings and captions. Only game metadata (name, description, stats) is sent — no personal data.

5. Data storage & security

All data is stored locally on the operator's own device or private server. No data is uploaded to any cloud service controlled by this application. The operator is responsible for securing their machine and credentials.

6. Data retention

Data persists in the local database until the operator deletes it. TikTok tokens may be revoked at any time through TikTok app → Settings → Connected Apps.

7. Your rights

You can revoke this app's access to your TikTok account at any time through TikTok's app settings.

8. Contact

This is a personal automation tool. For questions, contact the operator directly.
