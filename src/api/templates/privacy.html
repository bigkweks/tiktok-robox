Privacy Policy

Last updated: June 2025 · RoboxPipeline / RobloxGems

1. What this app is

RoboxPipeline is a personal content automation tool. It discovers Roblox games, generates photo carousel posts using AI, and publishes them to TikTok on behalf of its single operator (you). It is not a public service and does not have end-users other than its owner.

2. Data we collect
  • Roblox game data — publicly available information fetched from the Roblox public API (game names, descriptions, player counts, thumbnails). No personal data.
  • TikTok OAuth credentials — your Access Token and Open ID are stored locally in a .env file on your own machine/server. They are never transmitted to any third party other than TikTok's own API endpoints.
  • Content metadata — generated captions, ratings, and post history are stored in a local SQLite database (tiktok_robox.db) on your machine.
  • No user data — this app has no sign-up, no accounts, and collects no personal information from any person other than the operator.
3. How we use data
  • Roblox game data is used solely to generate TikTok content.
  • TikTok credentials are used solely to call the TikTok Content Posting API on your behalf.
  • Anthropic API is called to generate game ratings and captions. Game metadata (name, description, stats) is sent to Anthropic. No personal data is included.

5. Data storage & security

All data is stored locally on the operator's own device or private server. No data is uploaded to any cloud service controlled by this application. You are responsible for securing your own machine and .env credentials file.

6. Data retention

Data persists in the local SQLite database until you delete the tiktok_robox.db file. TikTok tokens may be revoked at any time through the TikTok app → Settings → Connected Apps.

7. Your rights (TikTok data)

You can revoke this app's access to your TikTok account at any time through TikTok's app settings. Doing so immediately invalidates the stored Access Token.

8. Contact

This is a personal automation tool. For questions, reach out to the operator directly.
