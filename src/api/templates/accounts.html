How 3×/day Posting Works

Each account gets 3 APScheduler cron jobs — one per posting slot. At each slot:

  1. The pipeline generates a new carousel (5 games, full approval + image gate)
  2. The carousel is queued in Buffer under that account's TikTok profile ID
  3. Buffer posts it at the next scheduled slot in your Buffer posting schedule

All accounts share the same discovered game pool. Per-account cooldown ensures no game repeats within 50 unique games on that channel — the same game can appear on two channels in the same week without issue.
